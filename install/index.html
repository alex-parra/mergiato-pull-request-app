Mergiato / Install

Install Mergiato in about a minute.

Three steps: download the app, allow it once on the first open, and sign in to the GitHub CLI if you haven't already. After that, updates install themselves.

Download for Mac

Free, no sign-up. For Apple silicon and Intel Macs.

1. Download and install

Download the latest .dmg: one universal file, under 10 MB, for Macs with Apple silicon or Intel. Open it and drag Mergiato to Applications.

2. Open it the first time

Mergiato isn't signed with an Apple Developer ID yet, so the first time you open it macOS says it can't check the developer. Allow it once:

  1. Open Mergiato from Applications, and close the warning.
  2. Go to System Settings → Privacy & Security and scroll to the Security section.
  3. Next to the line about Mergiato, click Open Anyway and confirm.

Updates don't ask again. Some company-managed Macs only allow apps from identified developers and block it entirely; that changes once Mergiato is signed.

3. Sign in to the GitHub CLI

Mergiato reads GitHub through the GitHub CLI (gh), signed in as you. If you already use gh, skip this step. Otherwise, install it and sign in:

brew install gh gh auth login

For GitHub Enterprise, add your server: gh auth login --hostname github.example.com. Without Homebrew, see cli.github.com for other ways to install it.

Open Mergiato again and your pull requests are there. There's nothing else to set up.

Optional extras

  • Vercel previews: install the Vercel CLI and sign in (npm i -g vercel, then vercel login) to see and deploy previews from each PR.
  • The docked terminal opens in your clone of the PR's repository. Mergiato asks for the folder the first time and remembers it.

Mergiato shows which tools it found at the foot of its sidebar, with their versions. A missing one is dimmed, and hovering says what it's for.

Updates

Mergiato checks for a new version 10 seconds after it opens and every 6 hours. When there is one, it offers it once with a Restart button. Every update is signed, and checked before it installs.

Uninstall

Drag Mergiato to the Trash. To remove its saved settings too, delete ~/Library/WebKit/com.mergiato.app and ~/Library/Caches/com.mergiato.app. Nothing needs to be revoked on GitHub, because Mergiato never had its own access. More on what it can access.

Questions

Why does macOS warn on the first open?

Mergiato isn't signed with an Apple Developer ID yet, so macOS can't check who made it. Allowing it once in Privacy & Security is enough; updates don't ask again.

Do I need a local clone of my repositories?

No. Everything comes from GitHub through the CLI. A clone is only for the optional terminal.

Does it run on Windows or Linux?

Not yet: macOS today, on Apple silicon and Intel. More platforms are coming.
