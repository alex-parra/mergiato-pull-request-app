Features

Everything a review needs, in one window.

Your inbox of PRs on the left, the PR on the right: description, activity, checks, the diff and its threads. No page loads, no tabs to juggle.

Big PRs

Thousands of files, still smooth.

No 50-file cap and no "diff too large": every file is there, and only the ones near your view are drawn, so scrolling stays fast whether the PR has 9 files or 900.

Review with Claude

Claude Code, in your clone, in one click.

Start a review with your own Claude Code skill, running in your local clone, in a terminal inside the app. Or have Claude draft the PR description from its commits and diff.

Vercel previews

Try it before you approve it.

Each project's preview, its state and its link, right under the description. Deploy the branch's latest commit, or redeploy, without leaving the PR.

Themes

Make it yours.

Dark, light or your Mac's own, in six variants. Press ⌥⌘T and flip through them on the app itself.

And more

Small things that add up.

Stacked PRs

Graphite stacks shown as they are: where a PR sits, what's above and below.

Checks that make sense

Each job's latest run, grouped and timed, with re-runs a click away.

Threads where they belong

Inline comments under their lines, resolved ones folded, long ones shortened.

Commit by commit

Step through a PR one commit at a time, or see everything at once.

Keyboard first

⌥↑ ⌥↓ between PRs, ⌘1–⌘4 between tabs, ⌘/ for the rest.

A terminal at hand

Shells and Claude sessions per PR, docked under it like VS Code's.

Install

Up and running in a minute.

  1. Download the latest .dmg, open it and drag Mergiato to Applications.
  2. First open: macOS can't verify the developer yet, so allow it once in System Settings → Privacy & Security → Open Anyway. Updates don't ask again.
  3. Sign in to GitHub with the GitHub CLI (gh auth login), if you haven't. Mergiato reads your PRs through it.

Needs macOS on Apple silicon and the GitHub CLI. Optional: Claude Code (Review with Claude) and the Vercel CLI (deploys). Mergiato updates itself.

FAQ

Questions

Is it free?

Yes, while in beta. Paid plans may come later, likely a one-time license; early users will hear first, and nothing you rely on will disappear overnight.

Does my code go anywhere?

No. Mergiato talks to GitHub through your own GitHub CLI and runs everything else on your Mac. There's no Mergiato server and no account.

Intel Mac, Windows or Linux?

Apple silicon Macs for now. Intel Macs are next; Windows and Linux aren't planned yet.

Why does macOS warn on the first open?

Mergiato isn't signed with an Apple Developer ID yet, so macOS can't check it. Allow it once in System Settings → Privacy & Security. Some company-managed Macs don't allow that at all; signing is planned.

Does it work with Graphite?

Yes: it shows Graphite stacks and the merge queue, and links each PR to its Graphite page.
