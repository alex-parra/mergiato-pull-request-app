Mergiato vs Pulldog

Both are desktop apps that keep pull requests out of browser tabs, and both talk to your Git host directly with no server in between. Pulldog is a code review client for many hosts. Mergiato goes deep on GitHub and covers the whole life of a PR: the ones you ship and the ones you review.

Pulldog details checked on 18 October 2026, from natic.app/pulldog, its pricing page and its Mac App Store listing. They change often; check its site for the latest.

The short answer

  • Pick Pulldog if you review on GitLab, Bitbucket, Gitea or Forgejo, juggle several accounts, or want Spotlight, widgets and an App Store install.
  • Pick Mergiato if you live on GitHub and ship through stacks, merge queues, GitHub Actions and Vercel previews, and you'd rather sign in once through the GitHub CLI.

Where Pulldog is the better pick

  • You review outside GitHub, on GitLab, Bitbucket, Gitea or Forgejo.
  • You switch between several accounts all day and want one inbox with your own filters.
  • You want Spotlight, widgets and notifications, and an app installed and signed through the App Store.

Where Mergiato is the better pick

  • Your work runs through stacked PRs and merge queues, and you want one button that merges the way each repo does.
  • You fix red builds yourself: see each Actions job and re-run just the failed ones.
  • You try the Vercel preview before you approve, or want a shell already in the PR's clone.
  • You'd rather not create tokens: Mergiato uses the GitHub CLI you're signed in to. What it can access.

Questions

Is Mergiato a Pulldog alternative?

On GitHub, yes, and it covers more of a PR's life: checks, stacks, merge queues and previews. If you review on other hosts, Pulldog covers them and Mergiato doesn't yet.

Does Mergiato work with GitLab or Bitbucket?

Not today: GitHub and GitHub Enterprise only. If you'd use it with another host, say so on GitHub issues.
